01. Perakitan Kabel LAN 🔌

Mengenal dan membuat kabel jaringan komputer

Apa Itu Kabel LAN?

Kabel LAN adalah media yang digunakan untuk menghubungkan perangkat komputer ke jaringan. Kabel yang sering digunakan adalah kabel UTP (Unshielded Twisted Pair) dengan konektor RJ45.

Alat dan Bahan

  • Kabel UTP
  • Konektor RJ45
  • Tang crimping
  • LAN tester
  • Cutter atau pengupas kabel

Urutan Warna Kabel T568B

Pin Warna Kabel
1Putih - Oranye
2Oranye
3Putih - Hijau
4Biru
5Putih - Biru
6Hijau
7Putih - Cokelat
8Cokelat

Langkah-Langkah Perakitan

  1. Siapkan seluruh alat dan bahan.
  2. Kupas bagian luar kabel UTP secukupnya.
  3. Pisahkan dan luruskan delapan kabel kecil.
  4. Susun warna sesuai standar T568B.
  5. Rapikan dan ratakan ujung kabel.
  6. Masukkan kabel ke konektor RJ45 sampai posisinya tepat.
  7. Gunakan tang crimping untuk mengunci konektor.
  8. Uji hasil perakitan menggunakan LAN tester.
💡 Tips: Pastikan susunan warna benar dan hasil pengujian LAN tester menunjukkan koneksi setiap pin dengan baik.

02. Membuat Website dari GitHub 💻

Publish your own website!

Apa Itu GitHub?

GitHub adalah platform untuk menyimpan, mengelola, dan membagikan kode program secara online. GitHub Pages memungkinkan pengguna mempublikasikan website statis secara gratis.

Langkah Membuat Website

  1. Buka website github.com.
  2. Login atau buat akun GitHub.
  3. Klik tombol New Repository.
  4. Masukkan nama repository.
  5. Pilih opsi Public.
  6. Klik Create Repository.
  7. Pilih Add File lalu Create New File.
  8. Beri nama file index.html.
  9. Masukkan kode HTML website.
  10. Klik Commit Changes.

Cara Mengaktifkan GitHub Pages

  1. Buka repository yang sudah dibuat.
  2. Pilih menu Settings.
  3. Klik menu Pages.
  4. Pada bagian Build and Deployment, pilih Deploy from a branch.
  5. Pilih branch Main dan folder /(root).
  6. Klik Save.
  7. Tunggu proses publikasi selesai.
  8. Buka alamat website yang diberikan GitHub.
🌐 Website kamu sekarang bisa diakses secara online! Pastikan file utama bernama index.html.

03. Konfigurasi IP Address 📡

Understanding computer networking

Apa Itu IP Address?

IP Address adalah alamat numerik yang digunakan untuk mengidentifikasi perangkat dalam jaringan komputer agar dapat saling berkomunikasi.

Jenis IP Address

  • IP Public: Alamat yang dapat dirutekan melalui internet.
  • IP Private: Alamat yang digunakan dalam jaringan lokal.
  • IP Static: Alamat yang diatur secara manual.
  • IP Dynamic: Alamat yang diberikan secara otomatis, biasanya melalui DHCP.

Komponen Konfigurasi IP

  • IP Address: Alamat perangkat.
  • Subnet Mask: Menentukan bagian jaringan dan host.
  • Default Gateway: Jalur menuju jaringan lain.
  • DNS: Menerjemahkan nama domain menjadi alamat IP.

Contoh Konfigurasi IP

IP Address: 192.168.1.10

Subnet Mask: 255.255.255.0

Gateway: 192.168.1.1

DNS: 8.8.8.8

Contoh tersebut merupakan konfigurasi jaringan IPv4 private. Gunakan alamat yang sesuai dengan jaringan yang sedang digunakan dan pastikan tidak terjadi konflik IP.

Cara Konfigurasi IP di Windows

  1. Buka Control Panel.
  2. Pilih Network and Internet.
  3. Klik Network and Sharing Center.
  4. Pilih Change Adapter Settings.
  5. Klik kanan pada Ethernet atau Wi-Fi.
  6. Pilih Properties.
  7. Klik Internet Protocol Version 4 (TCP/IPv4).
  8. Pilih Obtain an IP address automatically untuk DHCP, atau masukkan IP manual sesuai pengaturan jaringan.
  9. Klik OK untuk menyimpan.
