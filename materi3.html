Konfigurasi IP Address

Memahami alamat dan pengaturan jaringan komputer.

01. Pengertian IP Address

IP Address (Internet Protocol Address) adalah alamat numerik yang diberikan kepada perangkat jaringan untuk mengidentifikasi perangkat dan memungkinkan komunikasi antarperangkat.

02. Jenis IP Address

IP Public

Alamat yang dapat dirutekan melalui internet.

IP Private

Alamat yang digunakan dalam jaringan lokal.

IP Static

Alamat IP yang diatur secara manual.

IP Dynamic

Alamat IP yang diberikan secara otomatis, biasanya melalui DHCP.

03. Versi IP Address

IPv4

IPv4 menggunakan alamat 32-bit yang ditulis dalam empat bagian angka desimal. Contoh: 192.168.1.10

IPv6

IPv6 menggunakan alamat 128-bit yang ditulis dalam bentuk kelompok bilangan heksadesimal. Contoh: 2001:db8::1

04. Komponen Konfigurasi IP

  • IP Address: Alamat identitas perangkat.
  • Subnet Mask: Menentukan bagian network dan host.
  • Default Gateway: Jalur untuk menghubungkan jaringan lokal dengan jaringan lain.
  • DNS: Menerjemahkan nama domain menjadi alamat IP.

05. Contoh Konfigurasi IP

IP Address

192.168.1.10

Subnet Mask

255.255.255.0

Default Gateway

192.168.1.1

DNS

8.8.8.8
💡 Contoh ini menggunakan alamat jaringan private. Pastikan IP yang digunakan sesuai dengan jaringan dan tidak bertabrakan dengan perangkat lain.

06. Cara Konfigurasi IP di Windows

  1. Buka Control Panel.
  2. Pilih Network and Internet.
  3. Buka Network and Sharing Center.
  4. Klik Change Adapter Settings.
  5. Klik kanan pada Ethernet atau Wi-Fi.
  6. Pilih Properties.
  7. Pilih Internet Protocol Version 4 (TCP/IPv4).
  8. Klik Properties.
  9. Pilih Obtain an IP address automatically untuk DHCP, atau masukkan IP secara manual sesuai jaringan.
  10. Klik OK untuk menyimpan pengaturan.

07. Pengujian Koneksi Jaringan

Setelah konfigurasi selesai, koneksi dapat diperiksa menggunakan Command Prompt dengan perintah berikut:

ipconfig

Untuk melihat konfigurasi IP perangkat.

ping 192.168.1.1

Untuk menguji koneksi ke gateway contoh.
