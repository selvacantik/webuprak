LESSON 02 💻

Pembuatan Website dari GitHub

Belajar membuat dan mempublikasikan website sendiri.

01. Pengertian GitHub

GitHub adalah platform berbasis internet yang digunakan untuk menyimpan, mengelola, dan berkolaborasi dalam pengembangan kode program. GitHub menggunakan sistem version control Git.

02. Pengertian HTML, CSS, dan JavaScript

HTML

Menyusun struktur dan isi halaman website.

CSS

Mengatur warna, desain, dan tampilan website.

JavaScript

Menambahkan fungsi dan interaksi website.

03. Persiapan

  • Laptop atau komputer.
  • Koneksi internet.
  • Browser Google Chrome.
  • Visual Studio Code.
  • Akun GitHub.
  • Akun Vercel jika ingin melakukan deployment.

04. Membuat Repository

  1. Buka situs GitHub.
  2. Login menggunakan akun GitHub.
  3. Klik tombol New Repository.
  4. Masukkan nama repository, misalnya summer-tkj.
  5. Pilih Public agar repository dapat diakses secara publik.
  6. Klik Create Repository.

05. Mengunggah File Website

  1. Buka repository yang sudah dibuat.
  2. Klik Add File.
  3. Pilih Upload Files.
  4. Unggah index.html, materi1.html, materi2.html, dan materi3.html.
  5. Unggah folder css dan js beserta isinya.
  6. Klik Commit Changes untuk menyimpan perubahan.

06. Mengenal Supabase

Supabase merupakan layanan backend yang menyediakan database PostgreSQL, autentikasi, penyimpanan file, dan berbagai fitur untuk aplikasi web.

Supabase dapat digunakan untuk menyimpan data komentar, akun pengguna, atau informasi lain yang dibutuhkan website.

🌐 Website statis tetap bisa berjalan tanpa Supabase. Supabase digunakan ketika website membutuhkan data yang disimpan dan diakses secara dinamis.

07. Mengenal Vercel

Vercel merupakan platform untuk melakukan deployment dan hosting website. Vercel dapat dihubungkan langsung dengan repository GitHub sehingga perubahan kode dapat dipublikasikan kembali.

08. Cara Deploy ke Vercel

  1. Buka Vercel.
  2. Login menggunakan akun GitHub.
  3. Klik Add New Project.
  4. Import repository summer-tkj.
  5. Periksa pengaturan project.
  6. Klik Deploy.
  7. Tunggu proses deployment selesai.
  8. Buka link website yang diberikan Vercel.
✨ Selamat! Website kamu sudah dapat diakses secara online.
